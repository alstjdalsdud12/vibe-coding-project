비전 & 문제 정의

기존 RPG의 한계

  • 캐릭터는 개발자가 미리 제작
  • 플레이어는 주어진 것 중에서 선택만 가능
  • 모두가 똑같은 캐릭터로 게임한다
  • 내 상상 속 캐릭터를 만들려면
    그림 실력·설계 능력 필요

우리의 비전

  • 사용자가 상상한 것을 텍스트로 입력하면
  • AI가 즉시 캐릭터를 완성해주고
  • 그 캐릭터로 바로 게임을 플레이한다
  • 플레이할수록 AI가 나의 소설을 써준다

AI 기능 구현

캐릭터 생성 AI

  • 외형·무기·컨셉·세계관 → 1 JSON으로 완성
  • 이름 · HP/ATK/DEF/MP 스탯
  • 고유 스킬 (컨셉 맞춤)
  • 레벨 5 · 10 · 15 스킬 3개 사전 생성
  • 배경 스토리 · 던전 지역명
  • 검증 실패 시 자동 재시도

AI 소설 생성

  • 레벨·전투 기록·습득 스킬 분석
  • 초보 → 단편 / 고레벨 → 장편 페이지
  • 스킬 이름이 전투 장면에 직접 등장

AI 출력 보호

  • 스키마 검증 (typeof 체크)
  • 한자 정규식 제거 /[一-鿿]/g
  • 실패 시 1회 재시도 → 기본값
모델: llama-3.3-70b-versatile via Groq API

ADR 5개 · 단위/통합 테스트 완료 · 설치 가이드 README 포함

ADR 요약 (질의응답 준비)
ADR-001 Unity 2D 선택 — 씬 관리·게임 루프·Android/iOS 동시 빌드 내장. Flutter/React Native는 게임 기능 없어 탈락.
ADR-002 Node.js + Express — Groq/Firebase SDK npm 제공, 비동기 I/O에 적합. Spring은 1인 프로젝트에 과대.
ADR-003 Firebase Firestore — 서버리스, JSON 캐릭터 데이터와 NoSQL 구조가 자연스럽게 일치. 무료 티어 충분.
ADR-004 AI 레벨업 스킬 생성 — 캐릭터 생성 시 함께 생성 → 추가 API 비용 없이 컨셉 맞춤 스킬 확보.
ADR-005 GameState 정적 클래스 — 씬 전환 시 데이터 유지, 어디서나 접근. LoadCharacter()로 캐릭터 전환 시 완전 초기화.
